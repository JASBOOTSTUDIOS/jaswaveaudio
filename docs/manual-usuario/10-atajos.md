# 10 · Atajos de teclado

Personaliza en **Atajos de teclado…** (`Ctrl+Shift+,`): busca, cambia, **Restaurar todo**.

Los atajos **no** se disparan con el foco en un campo de texto (salvo combinaciones con modificadores según el dispatcher).

## Transporte

| Acción | Default |
|--------|---------|
| Reproducir / Pausar | `Espacio` |
| Pausar | `Enter` |
| Detener | `Ctrl+Espacio` |
| Grabar | `Ctrl+R` |
| Bucle | `R` |
| Ir al inicio | `W` / `Home` |
| Ir al final | `End` |
| Metrónomo | `K` |
| Playhead ← / → | `←` / `→` |

## Proyecto

| Acción | Default |
|--------|---------|
| Nuevo | `Ctrl+N` |
| Abrir | `Ctrl+O` |
| Guardar | `Ctrl+S` |
| Guardar como | `Ctrl+Shift+S` |

## Edición

| Acción | Default |
|--------|---------|
| Deshacer | `Ctrl+Z` |
| Rehacer | `Ctrl+Y` |
| Cortar / Copiar / Pegar | `Ctrl+X` / `C` / `V` |
| Duplicar | `Ctrl+D` |
| Seleccionar todo | `Ctrl+A` |
| Dividir en playhead | (catálogo `editing.split`) |

## Pistas

| Acción | Default típico |
|--------|----------------|
| Mute | `M` |
| Solo | `Alt+S` |
| Armar | `Ctrl+Shift+R` |

## Herramientas Arrange

| Herramienta | Default |
|-------------|---------|
| Seleccionar | `1` |
| Mover | `2` |
| Lápiz | `3` |
| Split | `4` |
| Borrador | `5` |

## Ventanas

| Acción | Default |
|--------|---------|
| Paleta de comandos | `Ctrl+Shift+P` |
| Atajos | `Ctrl+Shift+,` |
| MIDI Learn | `Ctrl+Shift+M` |
| Toggle paneles | `Ctrl+B` / `Ctrl+J` (según catálogo) |

## Piano roll (resumen)

Ver también tooltips del piano roll (`?`):

- `V` seleccionar · `D`/`B` dibujar · `E`/`X` borrar  
- `Q` cuantizar · `G` velocidad · `F` expresión  
- `↑↓` semitono · `←→` mover en tiempo  

## Zoom

- Timeline: `Ctrl+=` / `Ctrl+-` · `Ctrl` + rueda  
- Docs (con foco): zoom tipográfico del markdown  
- Terminal: `Ctrl+`` abre la pestaña; dentro, `Ctrl+L` equivale a `limpiar`
