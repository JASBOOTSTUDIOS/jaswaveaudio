# Manual de usuario — JasWave

Guía práctica para producir música en JasWave: interfaz, transporte, arrange, mixer, piano roll, VST, Asistente Jas (prompts), bounce y solución de problemas.

> Versión alineada con el producto **1.0** (criterio: terminar una canción y entregar un archivo).  
> Interfaz en **español**. Windows x64.

## Cómo usar este manual

1. Si es tu primera vez → empieza por [01 · Primeros pasos](./01-primeros-pasos.md).
2. Si quieres una canción rápido con IA → [08 · Asistente y prompts](./08-asistente-y-prompts.md) + [11 · Flujos prácticos](./11-flujos-practicos.md).
3. Si ya sabes DAWs → [07 · VST e instrumentos](./07-vst-e-instrumentos.md) y [09 · Mezcla y exportar](./09-mezcla-y-exportar.md).

## Qué puedes esperar (y qué no)

**Sí:** arrange, mixer, piano roll, VST3/VST2 x64, JasWave Roles/Piano, FX serial, sends, automatización vol/pan, freeze, bounce, Asistente Jas + Music Build, presets en Biblioteca.

**No en 1.0 (no te lo vendemos como listo):** sidechain audible, tomas/comping, macros, colaboración multi-usuario, IA generativa de audio, marketplace.

## Glosario rápido

| En la app | Significa |
|-----------|-----------|
| **Asistente Jas** | Chat de IA / copiloto |
| **Arrange** | Timeline de pistas y clips |
| **Construir** | Aplicar propuestas pendientes de la IA |
| **Music Build** | Orquestador: pistas + VST + MIDI + mezcla básica |
| **plan.md** | Plan vivo del proyecto (Docs) |
| **Biblioteca** | Presets de VST (proyecto / global) |
| **Freeze** | Consolida la pista a audio y bypass de plugins |
| **Armar** | Preparar pista para grabar |
| **Bucle / Repetir** | Loop de transporte |
