# Catálogo de Iconos de Instrumentos Musicales — JasWave

Este directorio contiene la librería oficial de iconos vectoriales de instrumentos musicales para **JasWave**, rediseñados con **alta fidelidad y realismo anatómico** en lienzo `64x64`.

---

## 1. Características Técnicas del Sistema de Iconos

- **Formato:** SVG estándar optimizado (Scalable Vector Graphics).
- **Lienzo / Resolución:** `viewBox="0 0 64 64"` para máxima definición anatómica y detalle de cuerdas, llaves, trastes, parches y controles.
- **Estilo:** Ilustración vectorial realista y moderna con doble nivel de opacidad (`fill="currentColor" fill-opacity="0.14"` y `fill-opacity="0.25"`) y contornos nítidos (`stroke-width="2"`).
- **Adaptabilidad dinámica (`currentColor`):** Cada icono adopta automáticamente el color asignado a la pista (`pista.color`) en el DAW y se integra nativamente en el tema oscuro de JasWave.
- **Rendimiento:** Peso medio de ~1.2 KB por icono (~68 KB en total para toda la librería). Cero impacto de memoria o arranque en el DAW.

## 3. Integración en JasWave

### 3.1. Estado del Proyecto y Modelo de Datos
En el modelo de dominio de JasWave (`shared/src/types/tracks.ts`), cada pista (`BaseTrack`) dispone del atributo opcional:
```typescript
interface BaseTrack {
  id: string;
  nombre: string;
  color: string;
  icono?: string; // Ejemplo: 'drums-acoustic', 'piano-grand', 'percussion-guira'
  // ...
}
```

### 3.2. Mutación por Comandos (Undo/Redo y Auditoría)
Para actualizar el icono de una pista manualmente o desde la IA:
```typescript
await tienda.executor.execute('track.update', {
  trackId: 'track-1',
  datos: { icono: 'percussion-guira' }
});
```

### 3.3. Renderizado en React (Cabecera de Pista y Mixer)
Los archivos se encuentran en la carpeta pública del frontend (`jas-wave/public/icons/instrumentos/`), por lo que pueden consumirse directamente vía URL:
```tsx
<img
  src={`/icons/instrumentos/${track.icono || 'track-audio'}.svg`}
  alt={track.icono}
  className="size-5 shrink-0"
  style={{ color: track.color }}
/>
```

## 4. Motor de Autodetección y Control por IA

El archivo complementario [`instruments-catalog.json`](./instruments-catalog.json) expone de forma estructurada las expresiones regulares (`trackNameRegex`), las categorías VST3 y las palabras clave asociadas a cada instrumento.

### Flujo de Detección:
1. **Al instanciar un plugin VST3:** JasWave consulta la categoría del plugin y el nombre del descriptor (p. ej. *Addictive Drums* detecta categoría `drums` -> `drums-acoustic.svg`).
2. **Al nombrar o renombrar una pista:** Se evalúa la expresión regular sobre el nombre asignado (p. ej. *"Bajo Slap"* asigna `bass-electric.svg`; *"Güira"* asigna `percussion-guira.svg`).
3. **Fallback manual:** Si el usuario hace clic sobre el icono de la pista, se abre un selector visual con buscador para reasignarlo en 1 clic.
4. **Interacción en Lenguaje Natural con la IA:** El usuario puede indicarle al asistente:
   - *"Ponle el icono de güira a la pista 3"*
   - *"Detecta los instrumentos de todas las pistas del proyecto"*
   El agente ejecuta `track.update` sobre el estado con el ID correspondiente.
