# JasWave Native Audio Engine (C++)

Addon N-API según [ADR-0009](../../docs/decisiones/ADR-0009-native-audio-bridge-napi.md).

## Build (Windows / MSVC o Build Tools)

```bash
cd native/audio-engine
npm install
npm run build
```

Si falla el build, la app usa Web Audio automáticamente.
